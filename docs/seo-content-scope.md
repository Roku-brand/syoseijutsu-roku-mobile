# 公開範囲と理論SEOの運用

公開範囲の正本は `src/data/content-scope.json` です。無料版は6人物像に属する処世術95件・理論150件、完全版は処世術336件・理論793件です。無料人物像と無料理論の入れ替えは、同ファイルの `free.personas` と `freeTheoryDisplayIds` を変更し、公開カタログ生成と監査を通して行います。

## 処世術の移行

従来の無料45件は維持し、既に無料公開されていた「人たらしの人」から次の5件だけを追加しました。

- master336-051｜好意を先に見せる
- master336-052｜相手の名前を呼ぶ
- master336-053｜相手の好きなものに関心を寄せる
- master336-054｜小さな変化に気づく
- master336-055｜以前の会話の内容を覚えている

正本に後から追加された master336-337〜356 は削除せず、現行商品の配信対象から外しています。これにより正本の履歴を保持しながら、完全版336件を再現します。

## 理論IDの照合

指定された150表示IDはすべて正本に存在し、重複はありません。140件は指定タイトルと完全一致しました。次の10件は同じID・同じ言葉ですが、正本タイトルに括弧または帰属表示があります。公開時は正本を優先しています。

- Q-1｜まず完成させてから改善する
- Q-4｜経験の意味は後から見つかる
- Q-5｜自分の価値観で時間を使う
- Q-6｜長期的な後悔を選択の基準にする
- Q-9｜失敗から大切なものを見直す
- Q-16｜結果より今日の行動に集中する
- Q-18｜考える時間と決断の質を分ける
- Q-25｜自分ならではの価値観を守る
- Q-32｜試してから判断する
- Q-40｜成功の裏にある試行錯誤を見る

正本に出典情報がない場合、詳細ページは帰属を追加で断定せず「出典不明」と表示します。Person構造化データも付与しません。

## SEO運用

- 1理論につき既存の `/theory/{id}` を唯一のcanonical URLとして使います。
- 無料150件だけをindex可能・sitemap収録とします。残り480件の詳細は `noindex,follow` です。
- 理論から処世術へのリンクは正本の紐づけだけを使います。
- 心理・行動・組織・戦略、実践知、古典・思想でtitle・見出しの検索意図を分けますが、正本本文を水増ししません。
- Search Consoleでは理論詳細の表示回数・クリック数・クエリ数・検索流入が発生した理論数を最優先で確認します。次に順位・CTR・index数、プロダクト側では理論から処世術／完全版への遷移を確認します。
- 入れ替え判断は十分な計測期間を置き、表示がほぼない理論と完全版側の有望理論を比較して行います。URLや正本タイトルは変更しません。

変更後は `pnpm content:build-public`、`pnpm content:audit-scope`、Web export、`pnpm seo:audit` の順で検証します。
