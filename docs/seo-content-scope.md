# 公開範囲と理論SEOの運用

公開範囲の正本は `src/data/content-scope.json` です。無料版は処世術50件・理論150件、完全版は処世術336件・理論630件です。無料理論の入れ替えは、同ファイルの `freeTheoryDisplayIds` だけを変更し、公開カタログ生成と監査を通して行います。

従来の無料45件は維持し、既に無料公開されていた「人たらしの人」から次の5件だけを追加しました。

- master336-052｜相手の名前を呼ぶ

## SEO運用

- 1理論につき既存の `/theory/{id}` を唯一のcanonical URLとして使います。
- 無料150件だけをindex可能・sitemap収録とします。残り480件の詳細は `noindex,follow` です。
- 理論から処世術へのリンクは正本の紐づけだけを使います。
- 心理・行動・組織・戦略、古典、格言でtitle・見出しの検索意図を分けますが、正本本文を水増ししません。
- Search Consoleでは理論詳細の表示回数・クリック数・クエリ数・検索流入が発生した理論数を最優先で確認します。次に順位・CTR・index数、プロダクト側では理論から処世術／完全版への遷移を確認します。
- 入れ替え判断は十分な計測期間を置き、表示がほぼない理論と完全版側の有望理論を比較して行います。URLや正本タイトルは変更しません。

変更後は `pnpm content:build-public`、`pnpm content:audit-scope`、Web export、`pnpm seo:audit` の順で検証します。
