# CMSの操作・画像・公開処理の修正（2026-10-16）

## 修正内容

- 特集CMSを「編集」「画像・掲載」「関連・出典」「プレビュー」に分けた。記事一覧にサムネイルと検索を追加。スマホは一覧と編集を切り替え、PCは二列で操作する。未保存の変更は切り替え・幅変更で消去しない。
- 保存・公開・結果表示を編集パネルの固定操作欄へ移した。長文の末尾まで移動せずに操作できる。入力不足は無反応の無効ボタンにせず、その場で案内する。
- 公開・非公開・削除の確認を中央のダイアログに変更。確認表示が長い編集画面の途中へ挿入される挙動をなくした。公開の二重実行を防止する。
- 共通CMSも保存・公開とAPIエラーをパネル下部に配置。スマホは階層・一覧と編集中の項目を切り替えられる。狭いPC幅で各パネルの最小幅の合計がはみ出す配置を縮めた。
- CMSを開いている間はメインアプリのタブナビゲーションを表示せず、編集領域を確保する。コンテンツ管理のヘッダーが「ホーム」になる誤表示も修正。
- APIが返す通常のオブジェクト形式のエラーも表示する。失敗しても入力を保持し、下書き保存後の公開失敗は再試行できる。

## サムネイルの整合性

読者の一覧では専用画像を使用していたが、CMSと記事詳細は `image_path` の元の汎用写真をそのまま表示していた。画像の解決処理を共通化し、CMSの一覧・画像欄・プレビュー・公開一覧・記事詳細で同じ画像を使用する。

専用サムネイルの元画像設定はCMSで「専用画像」と表示する。アップロードした写真・別の汎用写真を選択した場合は、その指定を優先する。タイトルだけの編集では専用のイラストを保持し、以前のタイトルに対応する装飾見出しは表示しない。

新しい画像や外部ライブラリは追加していない。既存の画像を使い、端末の画像キャッシュも共用する。これはCMSとアプリ内表示の整合性の修正であり、SNS側の画像キャッシュや共有用メタデータの変更は含めない。

## 公開処理

新規記事のURL名を省略すると、従来は空文字のまま公開RPCへ渡され、URLの検証で拒否されていた。空欄の場合は保存時に割り当てられる記事の既存キーをURL名として使う。入力されたURL名の検証と、公開後にURLを固定する制約は維持する。保存APIは確定したURL名を返し、フォームへ反映する。

公開時に関連IDがSQLの重複除去で並び替わる問題も修正し、選択した順番のまま最初の1件を残す。記事・理論・処世術の安定IDは転用・変更しない。

マイグレーション `20261016094111_fix_feature_publication_defaults.sql` をSupabase正本へ適用済み。既存のオーナー限定・security invoker・公開中の参照先検証・更新日時/下書き版による競合制御を保つ。既存の記事・下書き・画像・公開状態は更新しない。

## 検証

- 型検査・ESLint。
- 単体テスト: APIエラーオブジェクト、通常の例外、重複エラー、不明なエラーの表示。
- PGliteの実行テスト: URL名省略、関連順序、競合の拒否と再試行、匿名・一般利用者による公開拒否、既存記事の不変。
- 本番DB: 所有者権限でURL名省略から公開、競合後の再試行、匿名権限の公開拒否をトランザクション内で実行し、全テスト変更をロールバック。
- 本番照合: 既存7記事の差分0、残存テスト記事0、下書き0（作業開始時と同数）。変更前の関数定義2件を非公開バックアップに保存。
- ブラウザ回帰に、320/390/1440pxでの固定操作・ダイアログ・画像一致、公開失敗時の保持と再試行、入力不足の案内、URL名省略、共通CMSの幅変更・編集保持を追加。実際のオーナーログインは操作せず、ブラウザの編集操作はAPIモックで検証し、RPCは上記本番トランザクション検証を併用する。

Supabase Advisorの既存指摘（公開用definerビュー、既存RPC実行権限、漏洩パスワード保護設定）は今回の変更対象外。新しい権限の付与・RLSの緩和は行っていない。[ビューの指摘](https://supabase.com/docs/guides/database/database-linter?lint=0010_security_definer_view)、[RPCの指摘](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable)、[Auth設定](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)。
