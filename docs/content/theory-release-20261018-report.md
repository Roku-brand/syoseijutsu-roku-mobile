### 正本と生成・配信経路

- 編集上の正本はSupabaseのpublic.theories。CMSは既存のowner-theoriesと公開RPCで通常のカードとして編集する。
- 今回の著作原稿はscripts/theory-release-20261018-data.mjs、採否・別名の台帳はdocs/content/theory-release-20261018-*.json。生成器が公開前の固定スナップショットから再構成する。
- pnpm content:release-theories-945で正本スナップショット、関係データ、検索補助語、SQL、公開JSONを再生成できる。2回実行して同じ結果になり、追加の重複が生じないことをテストした。後日のCMS変更を検出した場合は上書きせず停止する。
- 本番DB移行は20261018112458_expand_theory_catalog_945.sql。public.theoriesの既存トリガーがpaid_contentを生成する。sync-paid-content.mjsは学習データの経路であり、理論をこのスクリプトで上書きしていない。
- ユーザー画面は公開用JSONを初期値に使い、public_theoriesを500件ずつ取得する。正規IDだけへ絞り込み、有効な完全版権限の本文を既存の安全な取得経路で補完する。CMSは1000件単位のページ取得を維持する。
