# マイページ参考画像の実装

## 表示

ユーザー指定の蔵書・閲覧履歴の2画面に合わせ、マイページを改修した。

- PCの本文幅を1,190pxに拡張。プロフィール、金色の利用状態バッジ、編集ボタン、巻物、タブ、見出しを同じ基準線に配置。
- 主要画面のPCヘッダーを高さ90px、左ナビゲーションを幅138pxに揃えた。高さ650px未満では左ナビゲーションの間隔を詰める。スマホの共通ヘッダー・下部ナビゲーションの寸法は維持。
- 座右の銘は既存の巻物に淡い山水を重ね、明朝体の文字を中心に表示。編集操作と100文字までの保存に対応。
- 閲覧履歴・蔵書・マイ処世術は、深緑の選択状態と金色のアイコン・下線で統一。
- 蔵書・マイ処世術のフォルダーは和紙の横長カード。すべては金、未整理は竹、対人術は青海波、仕事術は桜の背景。既存の任意名称にも対応。
- 閲覧履歴は処世術・理論・特集の3種類を維持。各行は左画像、分類、題名、概要、遷移矢印を表示。蔵書の「整理」は記事を開く操作から独立。
- 768px未満ではフォルダーを1列にし、プロフィール・見出し・本文のサイズを調整。長い座右の銘や任意のフォルダー名は折り返す。

画像内のオーナー名・完全版状態・サンプル件数は固定表示しない。ログイン中のプロフィール、権限、保存内容をそのまま表示する。

## データと負荷

データ構造、保存キー、安定ID、フォルダーID、履歴ID、アクセス制御は変更していない。DBマイグレーション・追加API・購読処理はない。内容の20件ずつの表示、特集一覧のキャッシュも維持。

背景4点の合計は138,626 B（約135.4 KiB）。フォルダー数が増えても4点を再利用する。背景はWebPで、Expo Imageのmemory-diskキャッシュを使用する。マイページの巻物で竹背景を先に使用するため、蔵書表示では同じ画像を再利用できる。無制限の画像生成・動画・アニメーションは追加していない。

アプリ共通のReact Nativeコンポーネントを更新。今回の公開対象はWeb版とし、iOS/Androidのネイティブビルドは実施しない。

## 確認

TypeScript、ESLint、Web export、公開ビルドの有料本文漏洩監査、SEO監査とPlaywright回帰テストで確認する。幅320 / 390 / 768 / 1672pxの専用テストでは、タブ高さ、フォルダー列数・件数、背景の読み込み、横幅、記事一覧、座右の銘編集を確認する。

スクリーンショットとローカルログは `.local-theory-backups/mypage-e2e-final/` に出力。テスト用の履歴・保存データはローカルのブラウザーだけに設定し、本番のユーザーデータは変更しない。

## 復元

この変更のコミットをrevertしてWebを再公開する。DB・保存形式の変更はないため、データ移行や復元処理は不要。

素材の生成プロンプトと書き出し条件は `assets/my-page/README.md` を参照。
