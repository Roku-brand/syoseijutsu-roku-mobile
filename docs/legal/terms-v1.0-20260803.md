# 処世術禄 利用規約 v1.0（2026年8月3日制定）

このファイルは、2026年8月8日改定前に購入手続へ適用されていた利用規約の履歴です。購入時点の契約条件を後から確認できるよう保存しています。

## 1. 適用・同意

本規約は、禄ブランド（以下「運営者」といいます。）が提供する「処世術禄」（以下「本サービス」といいます。）の利用条件を定めます。ユーザーは、本規約およびプライバシーポリシーに同意したうえで本サービスを利用するものとします。完全版の購入手続を完了した時点で、ユーザーと運営者との間に、購入画面および特定商取引法に基づく表記に示す条件による利用契約が成立します。

## 2. アカウント

完全版の購入および購入状態の復元にはアカウントが必要です。ユーザーは、正確な情報を登録し、認証情報を自己の責任で適切に管理してください。アカウントの第三者への譲渡、貸与、共有、売買または不正利用を禁止します。運営者は、不正利用またはそのおそれがある場合、事前の通知なく利用制限その他必要な措置を講じることがあります。

## 3. 購入・返金

完全版は、購入画面に表示する価格による買い切りのデジタルコンテンツです。定期課金はありません。決済はStripeを通じて行われ、利用権は購入に使用したアカウントにのみ付与されます。デジタルコンテンツの性質上、決済完了後のユーザー都合による取消し、返品または返金には応じません。ただし、法令により認められる場合および本サービスの内容が契約内容に適合しない場合はこの限りではありません。

## 4. 禁止事項・知的財産

ユーザーは、法令または公序良俗に反する行為、第三者の権利を侵害する行為、不正アクセス、リバースエンジニアリング、コンテンツの無断複製・転載・再配布・販売、または本サービスの運営を妨害する行為をしてはなりません。本サービスに含まれる文章、構成、デザイン、商標その他の権利は、運営者または正当な権利者に帰属します。法令上認められる範囲を除き、運営者の事前の書面による許可なく利用することはできません。

本サービスの内容は一般的な情報提供であり、特定の行動、成果、適法性、安全性、完全性、正確性、最新性または特定目的への適合性を保証しません。利用および情報の適用は、ユーザー自身の判断と責任で行うものとします。運営者は、保守、障害対応、セキュリティ、法令対応、事業上または技術上の必要その他合理的な理由により、本サービスまたはその全部・一部を変更、追加、停止または終了できます。重要な不利益変更または終了については、合理的に可能な範囲で事前に告知します。ただし、緊急の保守、安全確保または法令上の要請がある場合はこの限りではありません。

## 6. 免責・責任の範囲

通信回線、端末、外部サービス、第三者による不正行為その他運営者の合理的な管理を超える事由により生じた損害について、運営者は法令上責任を負う場合を除き責任を負いません。運営者の軽過失によりユーザーに損害が生じた場合、運営者の責任は、通常かつ直接に生じた損害に限られ、当該損害発生前12か月間にユーザーが本サービスのために実際に支払った金額を上限とします。運営者の故意または重過失による損害、ならびに法令により制限または免除できない責任については、この限りではありません。
