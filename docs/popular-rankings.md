# 人気ランキング

処世術部門・理論部門をそれぞれ10件で公開します。閲覧イベントの集計は順位に使いません。

## 編集

オーナーでログインし、「コンテンツ管理」→「人気ランキングを編集」を開きます。記事を変更して、上下ボタンで順位を指定し、「ランキングを公開」を押します。部門を切り替えても未公開の編集は保持します。公開は部門ごとです。

公開中の記事のみ選択可能です。同じ記事の重複、10件以外、同時編集による古い設定の上書きをDBで拒否します。掲載中の記事をアーカイブ・削除する場合は、先にランキングで別の記事へ差し替えます。本文、カテゴリ内順序、理論の表示IDとは独立しています。

## 正本と権限

正本はSupabaseの`popular_rankings`。`get_popular_rankings`はタイトル・カテゴリ・順位・アクセス区分のみを公開し、完全版本文を返しません。CMS候補取得と公開RPCは所有者を確認します。匿名には公開RPCへの実行権限がなく、テーブルの直接更新権限もありません。

`tests/sql/popular-rankings.sql`は本番DB上でトランザクションをロールバックして、匿名・非オーナーの拒否、オーナー公開、順位反映、重複・未公開記事・同時編集・アーカイブ保護を確認しました。DBアドバイザーの公開読み取り/所有者公開RPCに関するSECURITY DEFINER通知は意図した権限です。読み取りは本文なし、公開処理は所有者チェックと明示的なEXECUTE制御を持ちます。

ネットワーク接続に失敗した場合は、同梱の初期ランキングを表示してその旨を案内します。CMSでの変更は再ビルド不要で、ランキング画面を開き直すと反映されます。

## 画像

組み込みimagegenで生成した素材をWebP化して同梱しています。`assets/rankings/categories.webp`は9カテゴリの写真を3×3で収めた1枚の画像で、`src/components/ranking-art.tsx`がカテゴリごとに固定の領域を表示します。同一カテゴリの記事は同じ写真を使います。新規カテゴリは古典の写真を代用します。`assets/rankings/hero.webp`は花瓶と白い花のヒーロー画像です。両画像の合計は約342KBです。

生成プロンプト（要約）:

- カテゴリ素材: photorealistic-natural。均等な3×3、隙間・文字・ロゴなし。対人術=二つの陶器の茶杯、仕事術=ノートと万年筆、人生術=緑の葉、心理学=水滴と波紋、行動科学=水面の飛び石、組織・経営論=木製会議室、戦略論=木製チェス、実践知=陶器を整える手、古典・思想=古書と花枝。自然な朝の光、生成りと淡い金、中心に被写体。
- ヒーロー: photorealistic-natural。右側に手作りの生成りの花瓶と白い花枝、左側は見出し用の静かな余白。柔らかい金色の朝日、クリーム色の壁、自然な陶器の質感。文字・ロゴ・UIなし。
