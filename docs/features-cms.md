# 特集の運用

公開ページは `/features`、編集画面は `/owner/features`。オーナーはマイページの「特集管理」や既存CMSの「特集を編集」から入れます。

特集は無料公開の読み物です。ホームは保存済みのショートカットだけを「特集」に変更し、保存した記事は従来のライブラリから読めます。

## 編集と公開

記事を選択し、タイトル、導入文、写真、本文を編集します。本文は空行で段落を分け、`## 見出し`、`### 小見出し`、`**太字**`、`- 箇条書き`、`> 引用`を使えます。HTMLは実行されません。約2,000字は目安で、字数を合わせたり定期更新したりする必要はありません。

「下書きを保存」では読者が見る本文は変わりません。「プレビュー」で実際の記事レイアウトを確認し、「公開する」から反映します。非公開にした記事も本文と下書きが残ります。公開後のURL名は固定です。

「ヒーローに掲載」でページ上部に、「一覧に掲載」でカード欄に表示します。どちらも掲載順の小さいものから並びます。ヒーローが複数ある場合は写真の選択ボタンが現れます。初期の指針記事はヒーローと一覧、ほかの3記事は一覧に掲載します。

## 主カテゴリ

記事の中心となる問いを基準に「人間関係」「自己理解・成長」「生き方・選択」「社会・時代」から一つ選びます。既存の処世術・理論の分類とは独立しています。「すべて」は一覧のフィルタで、保存するカテゴリではありません。タブの順は「すべて」から上記4分類です。記事の掲載順を保ち、未設定の記事も「すべて」に表示します。

表示名とは別に `feature_articles.category_id` の `relationships` / `self-growth` / `life-choices` / `society-era` で保存します。下書きにも同じIDを持たせます。旧クライアントや旧下書きが項目を省略しても公開済みの分類を保持します。未設定は `null` で、不正な保存値はDBとRPCで拒否し、取得時に未知の値があっても記事自体を除外しません。

初期4記事の分類：

| 記事 | 主カテゴリ | 判断の中心 |
| --- | --- | --- |
| 押さえておくべき5つの処世術指針 | 生き方・選択 | 日々の選択と生活全体を支える指針 |
| ティルトを使いこなせ！ | 自己理解・成長 | 感情と俯瞰を行き来して自分の行動を変える |
| メタ発言はなぜ気分を害するのか | 人間関係 | 会話の中で相手をどう扱うか |
| 熱血と冷笑の本質 | 自己理解・成長 | 自分の関わり方と距離の取り方を見直す |

分類を保留した既存記事はありません。「熱血と冷笑の本質」はSNSの空気にも触れますが、中心は社会構造の分析より自己の関わり方の検討なので「自己理解・成長」です。「社会・時代」は現時点で0件となり、一覧に空状態を表示します。移行では本文・タイトル・関連する知識・公開状態を変更しません。指針記事の一覧への掲載はユーザー指定です。

写真は初期の海・森・山から選ぶか、アップロードして差し替えられます。写真の説明と関連する処世術・理論も設定できます。

日付、更新時刻、新着、読了時間は読者画面に出しません。公開用の本文とオーナー専用の下書きは別テーブルで、一般ユーザーには下書きを返しません。編集の競合を検出した場合は保存を止めて再読み込みを案内します。

## 初期記事

`content/features` の4記事は初回公開用の原稿です。以後のCMS編集を種データで上書きしません。自然写真は画像生成によるオリジナル素材です。

## 検証

`tests/e2e/features.spec.ts` は公開画面、保存・ライブラリ、スマートフォンの幅、CMSの下書き・プレビュー・公開・非公開を確認します。`supabase/tests/features.sql` は権限、下書きの隔離、編集の競合、公開・非公開をトランザクション内で検証し、最後にロールバックします。
