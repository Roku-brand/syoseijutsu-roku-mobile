# UI監査に基づく改修

## 方針

「毎日めくる、上質な知識帳」を基準に、墨色の本文・明朝の見出し・読みやすい操作文字・控えめな金線を組み合わせる。カードのID、理論の二重枠、お気に入りのフロントプレビュー、マイ処世術のフォルダーと保存データは維持する。

## 改修内容

| 監査項目 | 実装 |
| --- | --- |
| A01・A13 | 本文の標準を16px/28pxへ変更。ホームのショートカットを12pxの2行表示、学習の進捗・補助文を拡大。ホームの理論マップも縮小優先をやめて折り返す |
| A02・A16・A22 | 保存の読み上げ・通知・案内を「お気に入り」に統一し「保存／保存済み」を添える。一覧の保存操作をカード右上へ移し、IDとの重なりを避ける |
| A03 | 未取得の完全版シェルをおすすめ・続きから読む・履歴の完成カードとして表示しない。ホームで読込状態と再試行を提示 |
| A04・A20 | 特集の区切り線を描画し、題名と同一の冒頭見出しを省略。長文に章移動の目次を設置。特集ヒーローと一覧先頭の重複を解消 |
| A05 | 小画面の関連知識は関係・説明・読む操作を先に表示。選択可能な一覧を添える。PCの関係図は件数に応じた高さに変更 |
| A06 | 両一覧の分類タブを維持し、件数とページ選択を一段に統一。`1/10`などの表示から全ページを直接選択でき、前後移動にも対応 |
| A07 | 理論詳細の本文・関連知識・出典を820pxの同じ列へ。出典情報は開閉式に変更 |
| A08 | 学習の禄丸に専用領域を確保。回答ボタンや説明への重ね置きを廃止 |
| A09・A21 | お気に入りに現在の分類と解除を表示し、分類内0件と未保存を区別。探す・再試行の導線を用意 |
| A10 | 完全版利用中は購入画面の題名を利用情報に変更し、利用中表示の重複を整理 |
| A11・A15 | 特集の既存専用イラストとCMSの画像差し替えを尊重。汎用風景の代替には和紙・金線・題名を用いた共通の表紙を表示。知識カードは画像を抑え、題名と要旨を優先 |
| A12・A14 | 検索・保存・履歴の種類切替の選択色を墨色へ。小画面でヘッダーと繰り返す検索・保存・履歴・作成一覧の題名を省略 |
| A17・A18 | フォルダー名を24px/32pxへ調整し、本文・名前の文字数を表示。1行目が見出しになることと最初の保存先の関係を明示 |
| A19 | 後続調整で表記を「人気ランキング」に統一。編集部の推薦を示す文言と注記を削除。既存の順位管理は維持 |
| A23・A24 | ホーム自動切替を10秒、複雑な図は16秒にし、停止・再開を追加。保存用語と共通の節見出しの操作表現を整理 |

## 確認と適用範囲

TypeScript・ESLint・Web書き出し、およびブラウザーでの画面確認を実施。既存のUI仕様チェックを新しいページ選択、出典の開閉、関連知識一覧、保存用語に合わせて更新する。端末の保存形式・DB・認証・購入処理の変更は含まない。ネイティブ版への配布は別途ビルドが必要。
