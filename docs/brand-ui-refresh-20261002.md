# 処世術禄 ブランドUI刷新

## 既存構成と維持したデータフロー

- `src/app/_layout.tsx` → `BookHeader` と `PersistentBottomNav`。タブの共通ヘッダーとSafe Areaは画面本文から独立する。
- `src/app/(tabs)/learn.tsx` → 正規学習カリキュラムの識別情報、`useAppState().learningRecords`。回答と記録の保存は既存の `/learn/[caseId]` を利用。
- `MyPageContent` → `useAuth()` のプロフィール、`useAccess()` の完全版状態・利用期限、`useAppState()` の履歴・蔵書・座右の銘・マイ処世術・フォルダー。編集モーダルと詳細ルートを維持。
- Web `upgrade.tsx` → 既存Stripe購入確認・認証・復元・ホーム遷移。表示部品 `UpgradeLanding` のみに購入状態を渡す。
- iOS `ios-build20/src/app/upgrade.ios.tsx` → 既存StoreKit商品取得・購入・復元・購入監視・サーバー確認を維持し、同じ `UpgradeLanding` へ接続。新規ネイティブビルドは実行しない。

## UI

- 共通サブタイトルは「人生をうまく生きる方法を、すべての人へ」。検索・メニューの幅を保ち、320pxでは可読性を保つため2行を許容。
- 学ぶは対・仕・生の一本のロードマップ。挑戦ボタンは全ステージ同一、実記録の全体進捗・7個の状態ドット・実ケース名・ケース展開を表示。順番によるロックは導入しない。既存の無料／完全版の閲覧範囲は維持。
- 公開学習索引 `learning.index.json` は正規カリキュラムから生成した `id / stage / number / title` のみ。問題文・選択肢・正答・解説は公開索引に含めない。公開ビルド監査でも索引の完全一致と有料本文非混入を確認する。
- マイページ上部の外枠を除去し、プロフィールをフラットに、巻物をモバイル画面幅に近づける。保存データ・編集・期限表示は既存処理を維持。
- 完全版LPから端末モックアップの部品・スタイルを削除し、既存の山並み写真を大きく表示。購入バーは静かな黒・金に統一し、法的リンク・復元を維持。購入済みは価格を隠して「完全版を開く」に切り替える。

## 素材

山並み・書斎・巻物は既存素材。禄丸だけ内蔵imagegenで既存キャラクターを参考に生成した専用素材を使用。

- 保存先: `assets/learn/rokumaru-roadmap.webp`
- プロンプト: 既存の黒猫・金色の瞳・装飾・禄マークを維持し、机に伏せた落ち着いた案内役へ変更。薄い竹・障子・古書を右側に配置、左上にUI用の余白、透過背景、吹き出しや文字・UIは画像に入れない。

## 検証

型チェック、既存操作テスト、新規ブランドUI E2Eで320 / 390 / 430 / 1440pxの幅、共有ヘッダー、実進捗、ケース選択、保存データ、期限切れ／完全版利用中、再購入抑止、CTAと法的導線を確認する。iOS購入・データ保持の既存22テストも実行。

本番の実決済やiOS実機の新UI確認は新規ネイティブビルドを必要とするため、このソース修正では実行しない。UIの検証と決済の実課金成功は区別する。
