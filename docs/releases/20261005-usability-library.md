## 保存データの互換性

既存のAsyncStorageキーと保存IDを保持し、`libraryFolders` と `libraryFolderByItem` を追加。フォルダーのない従来データは未整理として表示する。所属キーは `technique:<id>` / `theory:<canonicalId>`。旧理論IDの所属を正規IDへ復元し、不明なフォルダーや保存されていないIDの所属は採用しない。

フォルダー削除は確認画面を経由し、内容を未整理へ戻す。保存した処世術・理論は削除しない。保存解除時は所属だけを解除する。完全版のカードも整理できるが本文は既存の購入・期限判定で保護する。

フォルダー情報は端末内保存。DBスキーマ変更、クラウド同期、新規依存パッケージ、コンテンツの統合・削除はない。
