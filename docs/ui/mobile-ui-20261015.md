# モバイルUI修正（2026-10-15）

## 変更

- ヘッダー・検索結果・探す画面の検索入力をスマホでも16px以上に統一。ピンチズームは制限しない。
- 特集一覧のスマホ用ヒーローを横並びにし、約176〜182pxの高さに圧縮。写真、全文のアクセシブルな記事名、読むボタンを維持。
- Webの画面高さを一つのコントローラーで管理。タッチ中は固定し、操作後の安定した高さを120ms後に反映。物理画面ではなく利用可能な高さに合わせ、キーボードの開閉にも対応。ピンチ中のvisualViewport縮小はレイアウトへ反映しない。
- ホームのリールは5秒ごとに次へ移動し、7枚目から1枚目へ循環。操作後は時間を数え直す。別画面・バックグラウンド・タッチ操作中・動きを減らす設定では停止。
- 完全版バナーを指定の3文に変更。期間と税込価格は購入処理と同じ定数を参照。
- マイ処世術の作成モーダルから上側の閉じるを削除。両方の作成入口と関連編集・フォルダー画面で自動入力フォーカスを廃止。Webのモーダルフォーカストラップも入力欄ではなくカードへ初期フォーカスする。
- ネイティブのホーム起動をタブナビゲーター内へ統一し、初回だけ親スタックがスライドする経路を解消。ネイティブのタブは事前マウントする。Webでは同じURLのルートグループ変更を別の画面遷移としてアニメーションしない。

## 検証

`tests/e2e/mobile-ui-polish.spec.ts` は320/390pxの文言と検索、両方の作成入口、5秒・手動操作・循環・別画面での停止、動きを減らす設定、タッチ中とピンチ中の高さ固定、初回タブのアニメーション回数、ホーム・理論一覧・長い特集本文の実タッチイベントによる上下スクロールを確認する。

既存の特集レスポンシブ検証は320〜1440pxで横長配置も確認。既存PWA検証は793→500→793pxのキーボード相当の高さ変更に追従することを確認する。

公開後は `node scripts/verify-mobile-ui-publication.mjs` で実際の公開URLを確認し、スクリーンショットと結果JSONを `test-results/production-mobile-ui/` に保存する。

ネイティブコードは型検査の対象。依頼によりiOS/Androidのビルド・ストア配信は実施しない。Safari実機での再現確認は未実施で、タッチ中のvisualViewport変動はブラウザで制御した回帰テストで確認する。
