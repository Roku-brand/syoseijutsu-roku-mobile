# 理論カードと格言カードの表示変更（2026-10-28）

## 変更
- 添付見本に合わせ、一重の淡い青枠・中央の濃紺見出し・短い直線・右上ID・右中央の矢印へ変更。
- 理論一覧のカード間隔を18pxへ調整。狭い画面では見出しと余白を縮め、全文タイトルを折り返す。
- 格言カードの補足を「ー著者・発言者」に統一。通常理論はこれまでどおり本文の一文目を表示。
- 無料版にも表紙情報として著者名だけを配信。本文・原典・権利情報の権限制御を維持。

## 確認
- TypeScriptと変更箇所のESLintは成功。
- 公開データの匿名読み取りでは格言39件に著者名があり、有料本文の露出は0件。
- 既存の見た目の期待値2箇所のみ新仕様へ更新。手動のテスト実行・テスト追加なし。
- 本番ビューの既存の公開条件を確認し、著者名の列だけを末尾に追加。

## 戻し方
- この変更を含むPRの逆コミットでカードの旧UIへ戻せる。
- 追加した著者名列は旧アプリから無視されるため、UIを戻す際にDBの列削除は不要。
