# 初回・完全版購入後のご案内

初回と完全版購入後に、それぞれ4ページのモーダル案内を表示する。生成り・墨色・金色、既存の写真・人物像素材を使用し、PCは画像と説明の2列、スマートフォンは縦配置にする。

## 初回

1. 処世術禄への歓迎と、日々の判断に役立つ知恵の紹介。
2. 人物像から処世術を探す方法。
3. ケース学習、蔵書、マイ処世術。
4. 無料開始と完全版紹介の入口。ログインは未ログイン時の全ページから利用可能。

表示済みの記録は `@shoseijutsu-roku/installation-welcome/v1` に保存する。プロフィール・サーバー・Keychainの記録を使わない。ネイティブのアンインストールで端末内の記録が消えるため、再インストール後はログイン済みでも初回案内を表示する。個人データの消去は案内の表示済み記録を変更しない。

Webの初回案内はホームとアプリ入口で表示する。法務、認証、購入、コンテンツへの直接リンクを遮らない。ネイティブではコンテンツリンクからの初回起動にも対応する。

## 完全版購入後

1. 購入へのお礼、解放された範囲、確認済みの利用期限、自動更新なし。
2. すべての人物像の紹介。「今すぐ人物像一覧を見る」から案内を終了して移動可能。
3. すべての処世術と背景の理論。
4. すべての学習ケース。最後の主ボタンは「人物像一覧を見る」。

購入成功の処理から案内を予約し、実際のアクセス状態が `paid`、確認結果が `active` になってから表示する。通常のログイン・復元・定期的な利用権確認・オーナープレビューでは購入案内を予約しない。アカウントと購入日時（なければ利用開始・終了日時）の組を保存し、同じ購入完了URLからの再表示を抑止する。新しい購入では再び案内する。

## 共通操作

- 全ページに「あとで」と「1 / 4」の進捗を表示。下部にもドットを表示する。
- 戻る・次へ、画像部分での左右スワイプ、Webの矢印キーに対応。
- EscapeやAndroidの戻る操作でも閉じられる。
- 「あとで」は表示済みとして記録し、自動で繰り返さない。設定から読み直せることを短いトーストで伝える。
- 設定の「はじめての方へ」と、購入済み時の「完全版の使い方」から再閲覧できる。
- 本文は必要に応じてスクロールでき、操作ボタンは固定する。320px幅では最後の選択ボタンを縦に並べる。
- OSの動きを減らす設定に従い、Webではモーダル内にフォーカスを保持する。画像の装飾テキストは重複読み上げを防ぐため読み上げ対象にしない。
- 端末ストレージの読み込みには時間制限を設け、保存に失敗しても閉じる操作を妨げない。

## 検証

`tests/e2e/installation-guides.spec.ts` で初回、端末記録消去による再インストール相当、ログイン・完全版紹介への遷移、購入成功・未確認・キャンセル、購入復元、同じ購入の再表示抑止、新しい購入、設定からの再閲覧、320/390/1440px幅を検証する。既存の回帰テストは初回案内を確認済みの状態で実行する。

iOS実装は既存のApp Store購入確認に接続する。実装時の検証は型検査とWebの表示・動作確認であり、新しいネイティブビルドやApp Store提出は行わない。
