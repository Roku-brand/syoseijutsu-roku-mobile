# iOS 1.0.0（23）— 探す画面とプライバシー表示順

ユーザーが2026年10月2日に新しい「探す」UIへの更新とビルドを明示。作成は1回。

## 変更

- 旧UIを優先していた `src/app/(tabs)/discover.ios.tsx` を削除し、iOSも共通 `discover.tsx` を利用。旧専用ファイルは過去の水平リール対策だったが、新しいカテゴリ索引には水平リールがない。
- 検索欄、人物像・理論への横並び導線、人物像3カテゴリ、理論6カテゴリ、人気検索を既存ルーティング・実データのまま使用。
- 検索入力の高さを52に定め、ネイティブのスクロール内で親の未確定高さを参照しない。
- iOSビルド前チェックに、未レビューの旧プラットフォーム専用「探す」が再び優先されることを防ぐ検査を追加。
- プライバシーポリシーの「運営者・お問い合わせ」を最後のセクションへ移動。運営者・窓口・開示請求の文面や他の法的文書は変更しない。Webにも同じ移動を適用。

## 検証

型チェック、単体48件、関連ブラウザ3件（320px／390px・検索・カテゴリ遷移）、iOS事前チェックが成功。390pxプレビューを視覚確認。

iOS exportのソースマップを確認し、共通「探す」が現在のソースと完全一致、旧iOS専用ルート不在、運営者情報が最終セクションであることを照合。ソース確認と実機検証は区別する。
