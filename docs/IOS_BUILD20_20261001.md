事前のEAS/ASC照合で、完了済み・TestFlight登録済みの最新ビルドは `1.0.0 (19)`。ASCの処理状態は `VALID` でした。EASの共有採番カウンターは `23` だったため、自動採番を使うと要求の20になりません。

このチェックアウトでは `cli.appVersionSource=local`、`build.build20` は `production` を継承し `autoIncrement=false`、`app.json` の `ios.buildNumber=20` としました。共有カウンターを巻き戻していません。アップロードは既存の `submit.production` を使います。この固定設定はビルド20専用で、次回のビルドを同じ番号で作らないでください。

```sh

```

この処理の範囲は署名済みIPAの作成とApp Store Connectへのアップロードです。App Reviewへの審査提出・一般公開は含みません。
