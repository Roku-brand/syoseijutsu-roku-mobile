# ホームの循環アニメーションと種類選択

## 変更

- 順送りは手前のカードを左端まで引き出し、重なりを最下段へ変更してからデッキへ差し込む。次の4枚は一段ずつ手前へ移動する。戻る操作は従来どおり最下段の直前カードを右から手前へ戻す。
- 重なりの変更はカードがデッキを完全に離れた瞬間だけ行う。完了時の5枚の座標・角度・縮尺・不透明度は次の論理順序の静止位置と一致する。
- WebはドラッグをrAFにまとめ、指を離した後はWeb Animations API。iOSはAnimatedのnative driver。二段階の基準時間は約360ms、スワイプ速度・既に引き出した距離によって短縮する。動きを減らす設定では即座に切り替える。
- 「シャッフル」の隣に選択中の種類を表示するボタンを追加。「すべて」「対人術」「仕事術」「人生術」「理論」をポップアップで選べる。
- 「すべて」は既存の混合推薦。その他は、無料版・完全版のアクセス境界を適用した実コンテンツの候補から、指定した種類だけを5枚選ぶ。種類変更もデッキを切り直す演出を使う。
- シャッフルは選択中の種類を維持して5枚を全交換する。候補が少ない場合に限り、未採用の候補を優先して必要な枚数だけ再循環させる。同じIDをデッキ内で重複させない。
- 種類・順序・位置は既存の端末内デッキ保存データに含める。以前の保存データは「すべて」として復元する。詳細往復・再読み込み・日本時間の日替わりでも選択は維持する。
- ポップアップは44px以上の操作領域、ラジオ選択の読み上げ、フォーカス表示、上下キー・Home/End・Escape、背面タップによる閉じる操作に対応。低い画面では選択肢をスクロールできる。

無料版の従来LPバナー、全幅カルーセル、PC両側の矢印、保存・履歴・既存ルートを維持。スワイプ中のシャッフルボタンは不透明度1を維持し、描画するカード画像も2枚を維持する。新規の画像生成や依存追加はない。

## 検証

- 型検査・全体Lint、Web/iOSバンドル出力。
- 15件の単体テスト：前後移動の幾何学的整合性、無料版/完全版×5種類、再現性・全交換・アクセス制御・候補が少ない場合の再循環。
- Chromium・WebKitでホームと新しい種類選択を検証。375/390/430/768/1440pxの表示、前後スワイプ、選択・全交換、保存、詳細往復、再読み込み、日本時間の更新、キーボード操作を含む。
- CPU 4倍低速化、8回スワイプ：平均16.91ms、95%点16.8ms、99%点33.3ms、34ms超1フレーム。シャッフルボタンの不透明度は全サンプル1、画像ノード2。

最終CIと公開環境の確認結果はリリース後に追記する。iOSはバンドル出力までの検証であり、実機ビルドの配布は今回のWeb公開には含まない。


## CMS追加カードの復元補正

本番確認で、CMSにだけ存在するカードが再読み込み時の初期カタログから見つからず、別のカードへ入れ替わる競合を確認した。保存済みID・カテゴリが初期カタログと一致しない場合のみ、既存の公開カタログ更新を待ち、最新のアクセス境界に従って復元する。

完全版は権限付きデータの読み込み完了を待つ。通信失敗・6秒以上の待機では保存済みIDを破棄せず、既存の再試行UIを利用する。更新が遅れて成功した場合はカタログ更新通知により同じカードを表示できる。保存するのは引き続きIDのみで、完全版本文は保存しない。

追加の回帰テストでは、バンドルに存在しない12枚を700ms遅れて返し、5枚の順序・3枚目の位置・周回位置・選択種類を復元する。再読み込み2回と通信失敗後の再試行でも同一の状態を維持することを確認する。
