# アプリ全体の検証に基づく改善

対象は2026-10-29のアプリ全体検証レポート。コンテンツID・無料／完全版の境界・既存の5枚デッキを維持する。

## 実装

- 公開カタログのSQLは、1ステートメント内で権限を1回評価する。既存のsecurity barrierと旧理論IDの別名を維持。匿名／無料／購入者／失効／取り消し／オーナーの返却値を移行前と比較するPGliteテストを追加。
- Webルートの分割読み込みを有効化。カタログは見出しと無料本文を分け、更新日時が変わっていない無料本文の再取得を省略する。共有キャッシュには有料本文を保存せず、通信失敗時は直近の無料CMSデータを復元する。
- 取得失敗・端末保存失敗を案内し、再試行を提供。初期読み込みと操作の競合で履歴などが消えないよう、読み込み中の変更を順番に適用する。
- 個人記録をアカウントごとに分離。旧端末記録は残し、ログイン後の引き継ぎ／引き継がない選択を提供する。
- 設定にJSON出力・追加復元・置き換え・復元前に戻す機能。異なる内容でIDが衝突するメモ／フォルダーは両方保持する。
- 希望時のみの非公開クラウドバックアップ。本人だけのRLS、アカウント切替時の応答破棄、更新日時による上書き競合検出を実装。自動同期は行わない。
- 検索は公開済みの完全版タイトルも対象にし、人物像の入口とゼロ件時の別候補を表示。関連リンクの完全版表示と区切り文字も調整。
- 375pxのヘッダーの改行、詳細／検索の見出し階層、白文字の購入導線のコントラストを調整。
- 学習に時間制限なしの練習モード、手動／不正解からの復習リストを追加。
- 全ユニットテストをPRと公開CIへ追加。既存の歴史的格言のテストを、後日の承認済み概要改訂にも対応させる。
- オーナー専用RPCの匿名実行権限と、トリガー関数の直接実行権限を削減。意図した公開用の権限付きビューと、外部非公開テーブルの閉じたRLSは維持。
- 漏えいパスワード保護だけを有効化・再確認する手動Actionsを追加。管理APIの認証情報や設定全文は出力しない。
- 公開成果物に`content-build.json`を生成し、CMSで公開版の生成日時とその後の編集を確認できるようにする。READMEの機能・件数と個人記録のプライバシー説明も更新。

## 確認方法

全ユニットテスト、型検査、Lint、Web export、SEO監査、有料本文のビルド露出監査、ブラウザの既存回帰テストと新規バックアップ／アカウント切替／クラウド競合／練習モードの操作テストを行う。
本番公開はPRのチェック完了後に実施する。

実iOS端末・StoreKit決済・Google Search Consoleの所有者アカウントを用いた検証は、ローカルWeb検証と区別する。ネイティブの変更を配布するには別途ストア向けバイナリの更新が必要。
