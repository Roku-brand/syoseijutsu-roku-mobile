# 処世術禄

iOS追加（2026-09-09）の設定・提出は [iOSリリース手順](docs/IOS_RELEASE.md)、監査と実機未確認項目は [検証記録](docs/IOS_VERIFICATION.md) を参照してください。署名・TestFlight・本番適用は別途必要です。

「人生をうまく生きる方法を、すべての人へ。」を掲げる、Web／iOS／Android対応の処世術アプリです。

## 実装済み

- 処世術カードの縦型リール
- 関心カテゴリに基づくルールベース表示
- キーワードとカテゴリから探せる検索
- 人間関係／仕事／メンタル／人生／挑戦の体系表示
- 無料版は50件の処世術と150件の理論を収録
- 完全版は336件の処世術と793件の理論、全人物像・全紐づけを収録
- カード詳細、実践の視点、注意点、関連理論、関連カード
- 保存、閲覧履歴、関心カテゴリ
- ネイティブ共有
- 購入確認後に完全版コンテンツを端末へ保存。現在の権限をサーバーで確認できない場合は有料内容をロックし、無料版を利用できます
- 無料版はログイン不要。完全版の新規購入は決済前にアカウントを作成またはログインし、購入情報と利用権をそのアカウントへ紐づける。切り替え前のゲスト購入は、購入完了URLからメール確認付きで引き換え可能
- 広告、解析SDK、広告目的の行動追跡なし
- アプリ内プライバシーポリシー、利用規約、データ消去
- App Store／Google Play向け設定、EAS Build設定

## 開発

Node.js LTSとpnpmを用意します。

```sh
pnpm install
pnpm start
```

型検査とWeb版バンドル確認：

```sh
pnpm typecheck
pnpm export:web
```

## コンテンツ更新

公開Web版のデータを更新した後、次を実行します。

```sh
pnpm content:import
pnpm typecheck
```

無料公開コンテンツは変換済みJSONをバンドルします。完全版コンテンツは購入権限の確認後に安全な配信APIから取得し、購入者の端末へ保存します。
