# 処世術禄

「人生をうまく生きる方法を、すべての人へ。」を掲げる、Web／iOS／Android対応の処世術アプリです。

## プロダクト思想

知識を消費するだけで終わらせず、蓄積し、つなぎ、必要なときに繰り返し活用する「蓄積型・不朽型」の知識プロダクトです。処世術は行動、理論は仕組み、特集は複数の知識を横断した問いを扱います。一時的な話題性や更新頻度より、長く読み返せる価値を重視します。必要な改訂は行いますが、定期更新の義務や鮮度管理は設けません。

制作主体は処世術禄編集部。編集案内人は、問いと知識をつなぐ案内役です。詳細は [プロダクト思想](docs/product-philosophy.md)、[特集の編集部導入](docs/feature-editorial-desk-20261014.md) を参照してください。

## 実装済み

- 処世術カードの縦型リール
- 関心カテゴリに基づくルールベース表示
- キーワードとカテゴリから探せる検索
- 人間関係／仕事／メンタル／人生／挑戦の体系表示
- 無料版は95件の処世術と141件の理論を収録
- 完全版は356件の処世術と821件の理論、全人物像・全紐づけを収録
- 理論は6大分類・36内部分類。正本はSupabaseの`public.theories`。原典・権利を確認した歴史的格言19件、関係タイプ付きの知識ネットワーク、CMSの監査・公開制御に対応。詳細は[再体系化報告](docs/content/theory-knowledge-network-report-20261015.md)を参照
- カード詳細、実践の視点、注意点、関連理論、関連カード
- 保存、閲覧履歴、関心カテゴリ
- ネイティブ共有
- 購入確認後に完全版コンテンツを端末へ保存し、通信失敗時やオフラインでも購入状態を保持
- 無料版はログイン不要。完全版の新規購入は決済前にアカウントを作成またはログインし、購入情報と利用権をそのアカウントへ紐づける。切り替え前のゲスト購入は、購入完了URLからメール確認付きで引き換え可能
- 広告、解析SDK、広告目的の行動追跡なし
- アプリ内プライバシーポリシー、利用規約、データ消去
- App Store／Google Play向け設定、EAS Build設定

## 開発

Node.js LTSとpnpmを用意します。

```sh
pnpm install
pnpm start
```

型検査とWeb版バンドル確認：

```sh
pnpm typecheck
pnpm export:web
```

## コンテンツ更新

公開Web版のデータを更新した後、次を実行します。

```sh
pnpm content:import
pnpm typecheck
```

無料公開コンテンツは変換済みJSONをバンドルします。完全版コンテンツは購入権限の確認後に安全な配信APIから取得し、購入者の端末へ保存します。
